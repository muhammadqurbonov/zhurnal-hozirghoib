# Журнали донишгоҳ — давомот, бал ва хориҷшавии донишҷуён

Node.js (>=18), бе вобастагии беруна. Додаҳо дар `data/db.json` (версияи кӯҳна худкор ба навъи нав мегузарад).

    node server.js        # → http://localhost:3000

## Қоидаҳои журнал
- Ҳар фан ҷадвал дорад (рӯзҳои Душанбе–Шанбе ва вақти дарс), онро админ муқаррар мекунад.
- Омӯзгор танҳо фанни худро пур мекунад. Рӯзҳои гузаштаро ҳамеша пур кардан мумкин аст; рӯзи ҷорӣ — аз оғози дарс; санаи оянда ва рӯзҳои беҷадвал мумкин нест.
- Барои ҳар донишҷӯ: ҳозир/ғоиб ва бал (0–100). Тағйирот худкор захира мешавад.
- Админ: илова/нест кардани омӯзгор ва донишҷӯ, тағйири ҷадвал ва паролҳо, тасдиқи хориҷшавӣ.
